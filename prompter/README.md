# プロンプター

会話を聞きながら、知らない用語・略語の意味と、気をつけたい点を、その場でカード表示するWebアプリです。

**辞書は持ちません。** 意味の説明や注意点の判断は、使う人が自分で選んだAI(自分のAPIキー)が行います。
HTML/CSS/JavaScriptだけで動き、ビルドも中継サーバーも要りません。

## 使い方

1. 「設定」で、AIサービスを選ぶ(Claude・ChatGPT・Gemini・OpenAI互換)
2. 自分のAPIキーを入れる(キーの作り方へのリンクは、設定画面にあります)
3. 「接続テスト」で、つながるか確かめる
4. 「聞く」画面で「聞き取り開始」(または「デモ」や入力欄で試す)

| AIサービス | 既定のモデル | つなぎ方 |
|---|---|---|
| Claude | `claude-sonnet-5-5` (Haiku 4.5・Opus 5.5も選べる) | 公式SDK(`@anthropic-ai/sdk`)をブラウザ用にまとめたもの |
| ChatGPT(OpenAI) | `gpt-5.6-luna` | Chat Completions API |
| Gemini(Google) | `gemini-3.5-flash-lite`(速い。3.5 Flashも選べる) | Gemini API(generateContent) |
| OpenAI互換(上級者向け) | なし(自分で入れる) | Ollama・LM Studio・OpenRouterなど |

モデル名は変わりやすいので、使えない場合は、設定の「モデル一覧を取得」から選んでください。
会議中は速さが大事なので、軽いモデル(Gemini 3.5 Flash-Lite、Claude Haiku 4.5など)が向いています。接続テストで応答が遅い(8秒超)と、その旨を表示します。

## AIに送る内容と費用

- 送るのは、文字起こしの直近の数文と、すでに出た語の一覧だけです。音声そのものは送りません。
- 話の区切りを1秒ほど待ち、まとめて1回で送ります。同じ語は、二度は説明させません。
- 会議中は速さを優先し、AIが考える量を少なめに指定しています(Claudeは `effort: low`)。
- 「AIオン」のボタンを押すと、オフにできます。オフの間は、何も送りません。
- 料金は、各AIサービスの従量課金です。各サービスの管理画面で、利用上限を設定しておくと安心です。
- 組織の会議で使う場合は、外部のAIサービスに会話を送ってよいか、組織のルールを確認してください。

## APIキーの扱い

- キーは、この端末のブラウザの中(localStorage)だけに保存し、ブラウザから各AIサービスへ直接送ります。中継サーバーは通りません。
- 共有の端末では、設定の「この端末に保存する」をオフにしてください(画面を閉じるとキーが消えます)。
- GitHub Pagesで公開した場合、同じ `ユーザー名.github.io` の下にある別のページとは、ブラウザの保存領域が共通になります。自分以外が作ったページを、同じアカウントで公開しないでください。
- 画面のCSP(Content Security Policy)で、このアプリ以外のスクリプトは読み込まないようにしています。

## AIが使えないとき

AIが未設定・オフ・エラーのときは、簡易判定で動きます。英字の略語(例: NDA)と、気をつけたい言葉(契約・期限・金額・「必ず」など)だけを拾います。
意味は出せないので、カードの「詳しく」から、チャットのAI(Claude・ChatGPT・Gemini)に質問文を渡せます。

## 動かし方(手元で)

```bash
cd prompter
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

- `index.html` を直接開くだけでは動きません(モジュールとマイクに、`http(s)` が必要です)。
- iPhoneで使うには、`https` で公開する必要があります(このリポジトリは、GitHub Pagesで公開する設定済み)。Safariで開き、「ホーム画面に追加」するとアプリのように使えます。

## ファイル

| ファイル | 役割 |
|---|---|
| `app.js` | 画面、聞き取り、カードの保存、AIへの送信のタイミング |
| `ai/index.js` | AIサービスの切り替え口(画面はここだけを使う) |
| `ai/common.js` | AIへの依頼文、返ってくる形(JSON)、エラーの扱い |
| `ai/claude.js` | Claudeへの接続(公式SDK) |
| `ai/openai.js` | ChatGPT・OpenAI互換への接続 |
| `ai/gemini.js` | Geminiへの接続 |
| `detect.js` | AIを使わない簡易判定と、文字起こしの強調表示 |
| `vendor/anthropic-sdk.js` | Claude公式SDK(MITライセンス)。`tools/build-anthropic-sdk.sh` で作り直せる |

## テスト

```bash
node --test tests/prompter/*.test.mjs
```

判定ロジック、AIへの依頼の形、各サービスへの送り方とエラーの扱いを、通信を模擬して確かめます。

## Jevを足すとき

いまは、AIが「どの語を出すか」と「意味」を一度に返します。
Jev(はい確率・選択・点数を返すAI)を前段に置くと、「この発言はAIに送る価値があるか」「注意点の種類と重要度」を速く・安く判定でき、文章を作るAIへの送信を減らせます。
差し込む場所は、`app.js` の `flushAI` で `AI.analyze` を呼ぶ前です。
