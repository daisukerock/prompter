# プロンプター

会話を聞きながら、知らない用語・略語の意味と、気をつけたい点を、その場でカード表示するWebアプリです。

**辞書は持ちません。** 意味の説明や注意点の判断は、使う人が自分で選んだAI(自分のAPIキー)が行います。
HTML/CSS/JavaScriptだけで動き、ビルドも中継サーバーも要りません。

## 使い方

1. 「設定」で、AIサービスを選ぶ(Claude・ChatGPT・Gemini・OpenAI互換)
2. 自分のAPIキーを入れる(キーの作り方へのリンクは、設定画面にあります)
3. 「接続テスト」で、つながるか確かめる
4. 「聞く」画面で「聞き取り開始」(または「デモ」や入力欄で試す)

| AIサービス | 既定のモデル | つなぎ方 |
|---|---|---|
| Claude | `claude-sonnet-5-5` (Haiku 4.5・Opus 5.5も選べる) | 公式SDK(`@anthropic-ai/sdk`)をブラウザ用にまとめたもの |
| ChatGPT(OpenAI) | `gpt-5.6-luna` | Chat Completions API |
| Gemini(Google) | `gemini-3.5-flash-lite`(速い。3.5 Flashも選べる) | Gemini API(generateContent) |
| OpenAI互換(上級者向け) | なし(自分で入れる) | Ollama・LM Studio・OpenRouterなど |

モデル名は変わりやすいので、使えない場合は、設定の「モデル一覧を取得」から選んでください。

## 要点(Google検索で確認・Geminiのみ)

用語カードの「要点」を押すと、その話題を **Google検索で確かめた3行** にまとめます(何の話/いまの状況/注目点)。

- 文章は、届いた順に流れて表示されます。終わると、検索した日時・モデル・情報源のリンクが付きます。
- 検索で確かめられないことは、推測で書かずに「確認できませんでした」と書くよう指示しています。
- 使うモデルは、設定の「『要点』に使うモデル」で選べます(既定は `gemini-3.5-flash`。遅いときは `gemini-3.5-flash-lite`)。失敗したときは「速いモデルでやり直す」が出ます。
- 作った要点は、カードと保存カードに残ります(6時間以内は、作り直さずに表示)。
- Googleの規約に沿って、Googleが返す「検索候補」を、指定の見た目のまま表示します。外部のHTMLなので、スクリプトを動かさない別枠(sandbox付きのiframe)に入れています。
- 検索での裏付け(Grounding with Google Search)は、無料枠に回数の上限があります。
会議中は速さが大事なので、軽いモデル(Gemini 3.5 Flash-Lite、Claude Haiku 4.5など)が向いています。接続テストで応答が遅い(8秒超)と、その旨を表示します。

## まだ定着していない言葉

- AIは、専門用語や略語に加えて、まだ広く定着していない言葉(新語・造語・流行語、業界や一部の会社だけで通じる言い回しなど)も拾い、優先して出します。1回に出す言葉は、最大4つです。
- そうした言葉のカードには「新しい言葉」の印が付きます。
- 新しすぎるなどで、AIが意味に自信を持てないときは、意味を作らずに「意味は要確認」の印を付け、分かっていることだけを出します。「要点」(Google検索)や「詳しく」で確かめられます。
- AIを使わない簡易判定では、辞書を持たないため、新しい言葉は見分けられません(英字の略語と、気をつけたい言葉だけを拾います)。

## 聞き取り(Whisper)

設定の「聞き取り(音声認識)」で、会話を文字にする方法を選べます。

| 方法 | 中身 | 費用 |
|---|---|---|
| Whisper(Groq) | `whisper-large-v3`(精度重視・標準)か `whisper-large-v3-turbo`(速い) | 無料枠あり(1日2,000回・音声8時間、1分20回まで。2026年10月時点の目安) |
| Whisper系(OpenAI) | `gpt-transcribe`(標準)か `whisper-1` | 音声1分あたり約0.0045ドル。キーはChatGPTと同じ |
| 標準 | iPhoneなどの音声認識(ブラウザの機能) | なし |

- 既定はGroqです。Groqのキーを入れるまでは、標準の聞き取りを使います。
- マイクの音を、音の大きさで「話している部分」に区切り(周りの雑音の大きさを測り続け、それより十分大きい音を話し声とみなす)、区切りごとに16kHzのWAVにして送ります。静かな間は送りません。
- 区切りは、0.7秒黙ったところ。長く話し続けたときは、12秒をこえて少し静かになったところ(最大20秒)で区切ります。物音のような短い音は送りません。
- Groqには、無料枠に収まるよう、5秒ほど間をあけて、たまった発言をまとめて送ります(1回30秒まで)。
- 聞き間違いを減らすため、「聞き取りのヒント(よく出る言葉)」と、カードに出た言葉、直前の発言を、Whisperにヒントとして渡します。
- Whisperが、無音や雑音のときに作りがちな決まり文句(「ご視聴ありがとうございました」など)や、話していない部分は捨てます。
- 話している間は、文字起こし欄に「…」、送っている間は「(文字にしています…)」と出ます。止めたときに話している途中だった分も、区切って送ります。
- 止まらないための決まり:
  - キーの誤り・1日の上限・モデルが見つからないときは、標準の聞き取りに切り替えて続けます(理由は設定の「聞き取り」に出ます。設定を直すか、「聞き取りテスト」が通ると戻ります)。
  - 一度も文字にできないまま、つながらないのが2回続いたら(ブラウザから使えない場合など)、標準の聞き取りに切り替えます。
  - 文字にできていた後の通信の失敗は、5秒・10秒…(最大60秒)と間をあけて、同じ発言を送り直します。つながらない間の発言は、3分ぶんまでためておきます。
  - 混雑(1分あたりの上限)のときは、示された時間だけ待って送り直します。
  - 電話の着信などでマイクが止められたときは、開き直します。
- 「聞き取りテスト」は、1秒の無音を送って、キーとモデルで呼べるかを確かめます。
- 送った回数と音声の長さは、設定の「使ったトークン」に出ます(今日の分は、Groqの無料枠の目安になります)。
- 通信量は、話している時間1時間あたり約115MBです。

## 送る前の振り分け(Jev)

設定の「送る前の振り分け(Jev)」をオンにすると、発言をAIに送る前に、TypeSafeの **Jev** に判定してもらい、送る価値がありそうな発言だけをAIに送ります。
あいさつ・相づち・雑談などを送らずに済むので、AIの呼び出し回数とトークンが減ります(Geminiの無料枠の、1日の回数の上限にもかかりにくくなります)。

- Jevは文章を作らず、「はい」である確率(0〜1)だけを返すAIです。1回の呼び出しで、2つの問いを同時に聞きます。
  - 知らない言葉: 一般の社会人がすぐには説明できない語(略語・専門用語・カタカナ語・まだ定着していない新しい言葉など)が含まれているか
  - 気をつけたい点: 聞き流すと後で困りそうな点(約束・金額・期限・契約・依頼・懸念など)が含まれているか
- どちらかの確率が基準以上なら、AIに送ります。基準は「振り分けの強さ」で選べます(取りこぼしを減らす 15%・標準 30%・節約を優先 50%)。
- 取りこぼさないための決まり:
  - まだAIに送っていない英字の略語(例: KPI)があるときは、Jevに聞かずにAIに送ります。
  - Jevにつながらないときや、エラーのときは、振り分けずにAIに送ります。つながらないのが3回続いたら知らせ、5秒・10秒・20秒…(最大60秒)と間をあけて、また試します。
  - キーの誤り・残高不足などのときは、Jevを止めて知らせます(設定を直すか、「Jev接続テスト」が通ると再開)。
- 「詳しく」と「要点」は、利用者が押したときだけ動くので、振り分けません。
- 「Jev接続テスト」では、AIに送りたい例文と、送らなくてよい例文を判定し、それぞれの確率と、いまの強さでAIに送るかどうかを出します。
- 送らずに済んだ回数と、Jevで使ったトークンは、設定の「使ったトークン」に出ます(種類「振り分け(Jev)」)。
- Jevには、新しい発言の文字起こしだけを送ります(手がかりの直前の文や、すでに出た語の一覧は送りません)。TypeSafeのAPIキーは、AIのキーと同じく、この端末のブラウザの中だけに保存します。キーは、[TypeSafeのコンソール](https://console.typesafe.ai/)で作れます。
- 接続先は `POST https://api.typesafe.ai/v1/systemone`(モデル `jev-latest`、問いの型は Noul)。ブラウザから直接呼ぶため、TypeSafeがブラウザからの接続(CORS)を許可している必要があります。許可されていない場合は、接続テストで「Jevに接続できませんでした」と出ます(そのときも、アプリは振り分けずにAIに送って動き続けます)。

## 使ったトークンの表示

- 「聞く」画面の右上に、この画面を開いてから使ったトークン(入力+出力)の合計を出します。押すと、設定画面の内訳に移ります。
- 設定の「使ったトークン」には、種類ごと(自動判定・振り分け(Jev)・詳しく・要点・接続テスト)と、今日のモデルごとの、回数・入力・出力を出します。今日の分は、この端末に残ります(端末の日付で区切り、「記録を消す」で消せます)。
- 「要点」のシートと、接続テストの結果にも、その1回で使った数を出します。
- 数は、各AIサービスが応答に添えて返す値です(Claude・ChatGPTは `usage`、Geminiは `usageMetadata`)。料金と同じ数え方で、入力にはキャッシュから読んだ分とGoogle検索の結果を読み込んだ分を、出力にはAIが考えた分(思考)を含めます。Claudeの自動切り替え(fallbacks)が働いたときは、試したモデルの分も数えます。
- 数を返さない接続先(一部のOpenAI互換など)では、表示されません。料金そのものや無料枠の残りは、各サービスの管理画面で確かめてください。

## 画面

- スマホ: カードが画面いっぱいに並び、下に大きな「聞き取り開始」ボタン。文字起こしは細い帯にたたみ、タップで広がります。「要点」は下から出るシートで、下に引っぱると閉じます。
- タブレット・PC: 右側に文字起こし。「要点」は右から出るパネル(Escで閉じる)。
- 動き: 新しいカードは上から滑り込み、ほかのカードはなめらかに押し下げられます(位置と透明度だけを動かすので軽い)。端末の「視差効果を減らす(動きを減らす)」がオンなら、動きを止めます。

## AIに送る内容と費用

- 送るのは、文字起こしの直近の数文と、すでに出た語の一覧だけです。音声そのものは送りません。
- 「要点」を押したときは、その言葉と、出てきた一文と、今日の日付を送ります。
- 話の区切りを1秒ほど待ち、まとめて1回で送ります。同じ語は、二度は説明させません。
- 会議中は速さを優先し、AIが考える量を少なめに指定しています(Claudeは `effort: low`)。
- 「AIオン」のボタンを押すと、オフにできます。オフの間は、何も送りません(Jevにも送りません)。聞き取りにWhisperを使っているときは、AIがオフでも、音声はWhisperに送ります。
- 「送る前の振り分け(Jev)」をオンにすると、新しい発言の文字起こしを、TypeSafe(Jev)にも送ります。
- 料金は、各AIサービスの従量課金です。各サービスの管理画面で、利用上限を設定しておくと安心です。使った量の目安は、設定の「使ったトークン」で確かめられます。
- 組織の会議で使う場合は、外部のAIサービスに会話を送ってよいか、組織のルールを確認してください。

## APIキーの扱い

- キーは、この端末のブラウザの中(localStorage)だけに保存し、ブラウザから各AIサービスへ直接送ります。中継サーバーは通りません。
- 読み込み直しても、キーは消えません(いつも、このタブの中にも控えておくため。端末に保存できなかったときも残ります)。
- 共有の端末では、設定の「この端末に保存する」をオフにしてください(タブを閉じるとキーが消えます)。使い終わったら「このAPIキーを削除」も押してください。
- iPhoneでは、ホーム画面に追加したアプリと、Safariの画面とで、保存場所が別です。キーは、使う方で入れてください。
- GitHub Pagesで公開した場合、同じ `ユーザー名.github.io` の下にある別のページとは、ブラウザの保存領域が共通になります。自分以外が作ったページを、同じアカウントで公開しないでください。
- 画面のCSP(Content Security Policy)で、このアプリ以外のスクリプトは読み込まないようにしています。

## 聞き取りが途切れたとき

- 「聞き取り開始」を押した直後は「マイクを準備しています…」と出ます(初めてのときは、マイクの許可を求められます)。
- しばらく無音だった、などの普通の区切りで止まったときは、すぐに作り直して聞き続けます(表示は変わりません)。
- すぐ止まるのが続くときは(通信できない、など)、0.5秒・1秒・2秒…(最大8秒)と間をあけて立て直します。そのあいだは、ボタンを黄色にして「立て直しています」と出します。しばらく続けて聞けたら(または言葉が聞こえたら)、元に戻ります。
- マイクの許可がない、マイクを使えない、などのときは、立て直しても直らないので、止めて理由を出します。
- 画面が隠れている間は立て直さず、画面に戻ったときに立て直します。
- 音声認識は、使い回すと止まったあとに動かないことがあるので、毎回作り直します。

## 上限や通信の失敗のとき

- 1分あたりの上限(混雑)にかかったときは、サービスが示した時間(示されなければ20秒)待ってから再開します。送る間隔も広げ、うまく送れると少しずつ戻します。
- 1日の上限(Geminiの無料枠など)や残高不足のときは、待っても戻らないので、AIを止めて簡易判定で動きます。Geminiの1日の上限は、日本時間の16時ごろ(冬は17時ごろ)に戻ります。設定の「接続テスト」が通れば再開します。
- 通信の失敗が続いたときは、5秒・10秒・20秒…(最大60秒)と間をあけて、もう一度試します。
- 待っている間の発言は、簡易判定で拾います。たまった発言は、新しいものを優先して送ります(1回に約360文字まで。入りきらない古い分は簡易判定)。

## 保存カードのバックアップ

- 設定の「バックアップ」で、保存カードと「知っている」語を、1つのファイル(JSON)に書き出せます。APIキーと設定は含めません。
- 書き出したファイルを読み込むと、いまの保存カードに足します(同じカードは足しません)。別の端末への引っ越しにも使えます。読み込むファイルの中身は信用せず、決まった項目だけを取り出します(`https` 以外のリンクは捨てる、など)。
- 保存カードの画面に、まだ書き出していないカードの枚数を出します。
- iPhoneのSafariは、7日間開かないサイトのデータを消すことがあります。ホーム画面に追加して使うか、ときどき書き出してください。
- 端末に保存できなかったとき(保存領域がいっぱい、など)は、画面の上で知らせます。その場で書き出せます。
- 作ってから6時間たった要点は、開くと作り直すので、Googleの「検索候補」のHTMLは保存しません(保存領域の節約)。

## AIが使えないとき

AIが未設定・オフ・エラーのときは、簡易判定で動きます。英字の略語(例: NDA)と、気をつけたい言葉(契約・期限・金額・「必ず」など)だけを拾います。
意味は出せないので、カードの「詳しく」から、チャットのAI(Claude・ChatGPT・Gemini)に質問文を渡せます。

## 更新の直後に壊れないための仕組み

GitHub Pagesは、ファイルを最大10分ほど端末に残します。更新の直後は、古いファイルと新しいファイルが混ざって、うまく動かないことがあります。そのため、次の3つで防いでいます。

- 公開するときに、読み込み先のURLに版(コミット)を付けます(`tools/stamp-version.mjs`)。版が変わると別のファイルとして読まれるので、混ざりません。
- 画面(`index.html`)とプログラム(`app.js`)の版が違えば、1回だけ読み込み直してそろえます。
- 起動できなかったときは(読み込みの失敗など)、`boot.js` が「読み込み直す」ボタンつきの案内を出します。

いまの版は、設定画面の一番下に出ます。

## 動かし方(手元で)

```bash
cd prompter
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

- `index.html` を直接開くだけでは動きません(モジュールとマイクに、`http(s)` が必要です)。
- iPhoneで使うには、`https` で公開する必要があります(このリポジトリは、GitHub Pagesで公開する設定済み)。Safariで開き、「ホーム画面に追加」するとアプリのように使えます。

## ファイル

| ファイル | 役割 |
|---|---|
| `app.js` | 画面、聞き取り、カードの保存、AIへの送信のタイミング、要点のシート、使ったトークンの集計と表示、動き |
| `ai/index.js` | AIサービスの切り替え口(画面はここだけを使う) |
| `ai/common.js` | AIへの依頼文、返ってくる形(JSON)、使ったトークン数の形、エラーの扱い |
| `ai/claude.js` | Claudeへの接続(公式SDK) |
| `ai/openai.js` | ChatGPT・OpenAI互換への接続 |
| `ai/gemini.js` | Geminiへの接続(「要点」のGoogle検索・ストリーミングも) |
| `ai/jev.js` | Jev(TypeSafe)への接続。送る前の振り分けの判定と、接続テスト |
| `gate.js` | 送る前の振り分けの決め方(送る基準・止めるエラー・つながらないときの待ち時間) |
| `ai/whisper.js` | Whisper(Groq・OpenAI)への接続。ヒントの作り方と、結果の整え方 |
| `capture.js` | マイクの音を受け取り、発言ごとに区切って渡す(Whisperで聞き取るとき) |
| `capture-worklet.js` | マイクの音を、少しずつまとめて渡す(AudioWorklet) |
| `vad.js` | 発言の区切り方(音の大きさと、周りの雑音の大きさで判断する) |
| `audio.js` | 音の大きさ・周波数の変換・WAVの作り方 |
| `sttqueue.js` | Whisperに送る発言のため方・まとめ方と、失敗したときの決め方 |
| `detect.js` | AIを使わない簡易判定と、文字起こしの強調表示 |
| `boot.js` | 起動の見張り役(起動できなかったときに、読み込み直しを案内する) |
| `backup.js` | 保存カードの書き出し・読み込みと、端末に保存する形 |
| `pacing.js` | AIへ送る間隔(上限にかかったときに広げる)と、たまった発言の扱い |
| `recovery.js` | 音声認識が止まったときの立て直し方(待ち時間・止めるエラー・表示する文) |
| `vendor/anthropic-sdk.js` | Claude公式SDK(MITライセンス)。`tools/build-anthropic-sdk.sh` で作り直せる |

## テスト

リポジトリの一番上で実行します。

```bash
npm ci                            # テストの道具を入れる(初回だけ)
npm test                          # 単体テスト
npx playwright install chromium   # 通しテスト用のブラウザを入れる(初回だけ)
npx playwright test               # 通しテスト
```

- 単体テスト: 判定ロジック、AIへの依頼の形、各サービスとJev・Whisperへの送り方とエラーの扱い、振り分けの決め方、発言の区切り方とWAVの作り方、使ったトークン数の数え方を、通信を模擬して確かめます。
