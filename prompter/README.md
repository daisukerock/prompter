# プロンプター

会話を聞きながら、知らない用語・略語の意味と、気をつけたい点を、その場でカード表示するWebアプリです。

**辞書は持ちません。** 意味の説明や注意点の判断は、使う人が自分で選んだAI(自分のAPIキー)が行います。
HTML/CSS/JavaScriptだけで動き、ビルドも中継サーバーも要りません。

## 使い方

1. 「設定」で、AIサービスを選ぶ(Claude・ChatGPT・Gemini・OpenAI互換)
2. 自分のAPIキーを入れる(キーの作り方へのリンクは、設定画面にあります)
3. 「接続テスト」で、つながるか確かめる
4. 「聞く」画面で「聞き取り開始」(または「デモ」や入力欄で試す)

| AIサービス | 既定のモデル | つなぎ方 |
|---|---|---|
| Claude | `claude-sonnet-5-5` (Haiku 4.5・Opus 5.5も選べる) | 公式SDK(`@anthropic-ai/sdk`)をブラウザ用にまとめたもの |
| ChatGPT(OpenAI) | `gpt-5.6-luna` | Chat Completions API |
| Gemini(Google) | `gemini-3.5-flash-lite`(速い。3.5 Flashも選べる) | Gemini API(generateContent) |
| OpenAI互換(上級者向け) | なし(自分で入れる) | Ollama・LM Studio・OpenRouterなど |

モデル名は変わりやすいので、使えない場合は、設定の「モデル一覧を取得」から選んでください。

## 要点(Google検索で確認・Geminiのみ)

用語カードの「要点」を押すと、その話題を **Google検索で確かめた3行** にまとめます(何の話/いまの状況/注目点)。

- 文章は、届いた順に流れて表示されます。終わると、検索した日時・モデル・情報源のリンクが付きます。
- 検索で確かめられないことは、推測で書かずに「確認できませんでした」と書くよう指示しています。
- 使うモデルは、設定の「『要点』に使うモデル」で選べます(既定は `gemini-3.5-flash`。遅いときは `gemini-3.5-flash-lite`)。失敗したときは「速いモデルでやり直す」が出ます。
- 作った要点は、カードと保存カードに残ります(6時間以内は、作り直さずに表示)。
- Googleの規約に沿って、Googleが返す「検索候補」を、指定の見た目のまま表示します。外部のHTMLなので、スクリプトを動かさない別枠(sandbox付きのiframe)に入れています。
- 検索での裏付け(Grounding with Google Search)は、無料枠に回数の上限があります。
会議中は速さが大事なので、軽いモデル(Gemini 3.5 Flash-Lite、Claude Haiku 4.5など)が向いています。接続テストで応答が遅い(8秒超)と、その旨を表示します。

## 使ったトークンの表示

- 「聞く」画面の右上に、この画面を開いてから使ったトークン(入力+出力)の合計を出します。押すと、設定画面の内訳に移ります。
- 設定の「使ったトークン」には、種類ごと(自動判定・詳しく・要点・接続テスト)と、今日のモデルごとの、回数・入力・出力を出します。今日の分は、この端末に残ります(端末の日付で区切り、「記録を消す」で消せます)。
- 「要点」のシートと、接続テストの結果にも、その1回で使った数を出します。
- 数は、各AIサービスが応答に添えて返す値です(Claude・ChatGPTは `usage`、Geminiは `usageMetadata`)。料金と同じ数え方で、入力にはキャッシュから読んだ分とGoogle検索の結果を読み込んだ分を、出力にはAIが考えた分(思考)を含めます。Claudeの自動切り替え(fallbacks)が働いたときは、試したモデルの分も数えます。
- 数を返さない接続先(一部のOpenAI互換など)では、表示されません。料金そのものや無料枠の残りは、各サービスの管理画面で確かめてください。

## 画面

- スマホ: カードが画面いっぱいに並び、下に大きな「聞き取り開始」ボタン。文字起こしは細い帯にたたみ、タップで広がります。「要点」は下から出るシートで、下に引っぱると閉じます。
- タブレット・PC: 右側に文字起こし。「要点」は右から出るパネル(Escで閉じる)。
- 動き: 新しいカードは上から滑り込み、ほかのカードはなめらかに押し下げられます(位置と透明度だけを動かすので軽い)。端末の「視差効果を減らす(動きを減らす)」がオンなら、動きを止めます。

## AIに送る内容と費用

- 送るのは、文字起こしの直近の数文と、すでに出た語の一覧だけです。音声そのものは送りません。
- 「要点」を押したときは、その言葉と、出てきた一文と、今日の日付を送ります。
- 話の区切りを1秒ほど待ち、まとめて1回で送ります。同じ語は、二度は説明させません。
- 会議中は速さを優先し、AIが考える量を少なめに指定しています(Claudeは `effort: low`)。
- 「AIオン」のボタンを押すと、オフにできます。オフの間は、何も送りません。
- 料金は、各AIサービスの従量課金です。各サービスの管理画面で、利用上限を設定しておくと安心です。使った量の目安は、設定の「使ったトークン」で確かめられます。
- 組織の会議で使う場合は、外部のAIサービスに会話を送ってよいか、組織のルールを確認してください。

## APIキーの扱い

- キーは、この端末のブラウザの中(localStorage)だけに保存し、ブラウザから各AIサービスへ直接送ります。中継サーバーは通りません。
- 共有の端末では、設定の「この端末に保存する」をオフにしてください(画面を閉じるとキーが消えます)。
- GitHub Pagesで公開した場合、同じ `ユーザー名.github.io` の下にある別のページとは、ブラウザの保存領域が共通になります。自分以外が作ったページを、同じアカウントで公開しないでください。
- 画面のCSP(Content Security Policy)で、このアプリ以外のスクリプトは読み込まないようにしています。

## 上限や通信の失敗のとき

- 1分あたりの上限(混雑)にかかったときは、サービスが示した時間(示されなければ20秒)待ってから再開します。送る間隔も広げ、うまく送れると少しずつ戻します。
- 1日の上限(Geminiの無料枠など)や残高不足のときは、待っても戻らないので、AIを止めて簡易判定で動きます。Geminiの1日の上限は、日本時間の16時ごろ(冬は17時ごろ)に戻ります。設定の「接続テスト」が通れば再開します。
- 通信の失敗が続いたときは、5秒・10秒・20秒…(最大60秒)と間をあけて、もう一度試します。
- 待っている間の発言は、簡易判定で拾います。たまった発言は、新しいものを優先して送ります(1回に約360文字まで。入りきらない古い分は簡易判定)。

## 保存カードのバックアップ

- 設定の「バックアップ」で、保存カードと「知っている」語を、1つのファイル(JSON)に書き出せます。APIキーと設定は含めません。
- 書き出したファイルを読み込むと、いまの保存カードに足します(同じカードは足しません)。別の端末への引っ越しにも使えます。読み込むファイルの中身は信用せず、決まった項目だけを取り出します(`https` 以外のリンクは捨てる、など)。
- 保存カードの画面に、まだ書き出していないカードの枚数を出します。
- iPhoneのSafariは、7日間開かないサイトのデータを消すことがあります。ホーム画面に追加して使うか、ときどき書き出してください。
- 端末に保存できなかったとき(保存領域がいっぱい、など)は、画面の上で知らせます。その場で書き出せます。
- 作ってから6時間たった要点は、開くと作り直すので、Googleの「検索候補」のHTMLは保存しません(保存領域の節約)。

## AIが使えないとき

AIが未設定・オフ・エラーのときは、簡易判定で動きます。英字の略語(例: NDA)と、気をつけたい言葉(契約・期限・金額・「必ず」など)だけを拾います。
意味は出せないので、カードの「詳しく」から、チャットのAI(Claude・ChatGPT・Gemini)に質問文を渡せます。

## 更新の直後に壊れないための仕組み

GitHub Pagesは、ファイルを最大10分ほど端末に残します。更新の直後は、古いファイルと新しいファイルが混ざって、うまく動かないことがあります。そのため、次の3つで防いでいます。

- 公開するときに、読み込み先のURLに版(コミット)を付けます(`tools/stamp-version.mjs`)。版が変わると別のファイルとして読まれるので、混ざりません。
- 画面(`index.html`)とプログラム(`app.js`)の版が違えば、1回だけ読み込み直してそろえます。
- 起動できなかったときは(読み込みの失敗など)、`boot.js` が「読み込み直す」ボタンつきの案内を出します。

いまの版は、設定画面の一番下に出ます。

## 動かし方(手元で)

```bash
cd prompter
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

- `index.html` を直接開くだけでは動きません(モジュールとマイクに、`http(s)` が必要です)。
- iPhoneで使うには、`https` で公開する必要があります(このリポジトリは、GitHub Pagesで公開する設定済み)。Safariで開き、「ホーム画面に追加」するとアプリのように使えます。

## ファイル

| ファイル | 役割 |
|---|---|
| `app.js` | 画面、聞き取り、カードの保存、AIへの送信のタイミング、要点のシート、使ったトークンの集計と表示、動き |
| `ai/index.js` | AIサービスの切り替え口(画面はここだけを使う) |
| `ai/common.js` | AIへの依頼文、返ってくる形(JSON)、使ったトークン数の形、エラーの扱い |
| `ai/claude.js` | Claudeへの接続(公式SDK) |
| `ai/openai.js` | ChatGPT・OpenAI互換への接続 |
| `ai/gemini.js` | Geminiへの接続(「要点」のGoogle検索・ストリーミングも) |
| `detect.js` | AIを使わない簡易判定と、文字起こしの強調表示 |
| `boot.js` | 起動の見張り役(起動できなかったときに、読み込み直しを案内する) |
| `backup.js` | 保存カードの書き出し・読み込みと、端末に保存する形 |
| `pacing.js` | AIへ送る間隔(上限にかかったときに広げる)と、たまった発言の扱い |
| `vendor/anthropic-sdk.js` | Claude公式SDK(MITライセンス)。`tools/build-anthropic-sdk.sh` で作り直せる |

## テスト

リポジトリの一番上で実行します。

```bash
npm ci                            # テストの道具を入れる(初回だけ)
npm test                          # 単体テスト
npx playwright install chromium   # 通しテスト用のブラウザを入れる(初回だけ)
npx playwright test               # 通しテスト
```

- 単体テスト: 判定ロジック、AIへの依頼の形、各サービスへの送り方とエラーの扱い、使ったトークン数の数え方を、通信を模擬して確かめます。
- 通しテスト: ブラウザで画面を動かして確かめます(AIの応答は模擬し、実際には通信しません)。スマホ幅・PC幅・ダークモード・動きを減らす設定で、カード・要点・保存・使ったトークンの表示などを確かめ、コンソールのエラーやCSP違反が出たら失敗にします。
- GitHubでは、PRごとに両方を自動で実行します。`main` に入ったときも、テストが通った場合だけ公開します。

## Jevを足すとき

いまは、AIが「どの語を出すか」と「意味」を一度に返します。
Jev(はい確率・選択・点数を返すAI)を前段に置くと、「この発言はAIに送る価値があるか」「注意点の種類と重要度」を速く・安く判定でき、文章を作るAIへの送信を減らせます。
差し込む場所は、`app.js` の `flushAI` で `AI.analyze` を呼ぶ前です。
